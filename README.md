# ⏱️ Stream Timestamp

**Stream Timestamp** is a lightweight Chrome extension that automatically saves your current position in YouTube and Rumble videos, so you can return later and resume exactly where you left off — perfect for livestreams, podcasts, and long videos.

---

## 🚀 Features

- ✅ Saves your last watched timestamp automatically
- ▶️ Resumes playback from the saved position
- 🧠 Stores progress locally by video URL
- 🌐 Supports **YouTube** and **Rumble**
- 🔒 100% private — no sign-in or cloud sync

---

## 📦 Installation

1. Clone or download this repository.
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable **Developer Mode** (top right)
4. Click **Load Unpacked** and select the project folder.

---

## 🛠 How It Works

- A background script runs on YouTube and Rumble video pages.
- When you watch a video, your current timestamp is saved in `chrome.storage.local`.
- When you return to the same video later, the saved time is restored automatically.
- Seamless and silent — no interaction required.
