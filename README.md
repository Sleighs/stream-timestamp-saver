# Stream Timestamp Saver 

**Stream Timestamp Saver** is a lightweight Chrome extension that automatically saves your current position in YouTube and Rumble videos, so you can return later and resume exactly where you left off — perfect for livestreams, podcasts, and long videos.

---

## Features

- Saves your last watched timestamp automatically
- Resumes playback from the saved position
- Supports **YouTube**

---

## 🛠 How It Works

When you watch a video, your current timestamp is saved
- When you return to the same video later, the saved time is restored automatically.
- Seamless and silent — no interaction required.
